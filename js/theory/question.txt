9 : Describe how switch statements work in JavaScript. When should you use a
switch statement instead of if-else?

Checks a single expression against multiple case values.

Executes the matching case’s code block.

Use break to stop execution; without it, cases “fall through.”

default runs if no case matches.

When to use:

Use switch when comparing one variable to many fixed values.

Use if-else for complex or range-based conditions.

14 :  Discuss the concept of parameters and return values in functions

Parameters: Variables listed in a function definition that receive values (arguments) when the function is called.

Return Values: The data a function sends back using return; ends the function’s execution and passes the result to the caller.

17 :  What is an object in JavaScript? How are objects different from arrays?

Object: A collection of key–value pairs, where keys are strings (or symbols) and values can be any data type.

Difference from Arrays:

Objects store data as unordered key–value pairs.

Arrays store data as ordered elements with numeric indexes.

18 : Explain how to access and update object properties using dot notation and
bracket notation.

Dot Notation

let obj = { name: "John" };
console.log(obj.name); // Access → "John"
obj.name = "Mike";     // Update

Bracket Notation

let obj = { name: "John" };
console.log(obj["name"]); // Access → "John"
obj["name"] = "Mike";     // Update

22 : Explain the methods getElementById(), getElementsByClassName(), and
querySelector() used to select elements from the DOM.

1)getElementById(id)

Selects one element with the given id.

Returns a single element object or null if not found.

2) getElementsByClassName(className)

Selects all elements with the given class.

Returns an HTMLCollection (array-like)

3) querySelector(selector)

Selects the first element matching the CSS selector.

Can use #id, .class, or any valid CSS selector.

26 :  Why is error handling important in JavaScript applications?

Error handling is important in JavaScript because it:

Prevents crashes – Stops the whole application from breaking when an error occurs.

Improves user experience – Shows friendly error messages instead of blank screens or broken pages.

Helps debugging – Makes it easier to find and fix issues.

Ensures smooth flow – Allows the program to handle unexpected situations and continue running safely.
